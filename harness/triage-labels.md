# Triage Labels

The skills speak in terms of five canonical triage roles. In this repo a role is the value of a ticket's `**Status:**` line.

| Label in mattpocock/skills | Status in our tickets | Meaning                                  |
| -------------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer needs to evaluate this ticket |
| `needs-info`               | `needs-info`          | Waiting on more information              |
| `ready-for-agent`          | `ready-for-agent`     | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`     | Requires human implementation            |
| `wontfix`                  | `wontfix`             | Will not be actioned                     |

Work-in-flight states, not triage roles: `in-progress`, `done`.
